# Dependencias del runtime de K-Downloader (Python embeddable 3.13, cp313 win_amd64).
#
# build.ps1 las instala con:
#   pip install --target runtime\Lib\site-packages --platform win_amd64 --python-version 3.13
#               --implementation cp --only-binary=:all: --no-deps --require-hashes
# Por eso cada línea fija la versión exacta y el SHA-256 del archivo que se usa, y la lista
# incluye todas las dependencias transitivas (no se resuelve nada en el momento del build).
# Las líneas marcadas con "# sdist" no tienen wheel: build.ps1 verifica el hash del sdist,
# lo convierte en wheel con "pip wheel --no-deps" y lo instala aparte.
#
# pycryptodomex NO se incluye: con Smart App Control activo, Windows bloquea sus .pyd sin firma
# (diálogo "Bad Image" 0xc0e90002 en cada ejecución de yt-dlp). yt-dlp usa su AES en Python puro.
#
# Para regenerar los hashes: pip download -r <lista sin hashes> --platform win_amd64
#   --python-version 3.13 --implementation cp --only-binary=:all: y sha256 de cada archivo.
